# Ender-Proxy

**🇺🇸 Read in English: [README.md](README.md)**

Ender-Proxy는 마인크래프트 베드락 에디션(Bedrock Edition)용 MITM 프록시 클라이언트입니다. **Windows와 Android**를 지원합니다. 내 마인크래프트 클라이언트와 접속한 Xbox Live 세션(친구의 월드 또는 내 소유의 Realm) 사이에 위치해서 패킷을 그대로 중계하고, 이동/전투/월드/시각 효과 관련 유틸리티 모듈과 인게임 HUD, 그리고 외부 도구 연동 기능을 추가로 제공합니다.

모든 기능은 채팅에서 `.` 접두사가 붙은 명령어(예: `/.fly on`)로 조작하거나, 프록시 자체의 앱에서 조작합니다. Windows에서는 다크 테마 컨트롤 패널로, Android에서는 앱 자체와 마인크래프트를 벗어나지 않고 조작할 수 있는 플로팅 오버레이로 제공됩니다(Termux나 별도 런타임이 필요 없습니다).

> **개발 진행 중(WIP):** Ender-Proxy는 아직 초기 개발 단계입니다. 자잘한 버그나 다듬어지지 않은 부분이 있을 수 있으니 감안해주세요. 뭔가 안 된다 싶으면 먼저 [Releases](../../releases) 페이지에서 최신 버전인지 확인해보시고, 버그를 발견하면 [디스코드](https://discord.gg/rDUGPHn47V)로 제보해주시면 고치는 데 도움이 됩니다.

> **면책 조항:** Ender-Proxy는 현재 BDS(베드락 전용 서버) 및 Xbox Live 친구 세션에서 필수인 **서버 권위 이동(server-authoritative movement)** 방식을 대상으로 동작합니다. 클라이언트를 임의로 순간이동시키는 게 아니라 서버 자체의 시뮬레이션을 유도하는 방식입니다. 일부 모듈(전투 자동화, 이동 보조, 월드 조작 등)은 소유하지 않은 서버나 Realm의 규칙에 위배될 수 있습니다. 본인이 소유한 월드이거나 함께하는 모든 플레이어가 동의한 경우에만, 그리고 본인 책임 하에 사용하세요.

## 주요 기능

- **Xbox Live 친구 세션 탐색**: 본인의 Microsoft 계정으로 로그인해서, 서버 IP 없이도 Xbox Live 친구들이 열어둔 베드락 세션을 목록으로 보여줍니다.
- **인게임 명령어 메뉴**: HUD 패널(`/.menu`)과 `.` 접두사 기반의 전체 채팅 명령어 세트를 제공합니다.
- **이동**: `fly`, `speed`, `noclip`, `nofall`, `scaffold`, `blink` / `autoblink`.
- **전투**: `killaura`, `multiaura`, `reach`, `autoclick`, `autototem`.
- **월드**: `fastbreak`, `automine`, `nuker`, `chunkloader`.
- **시각 효과**: `esp`, `xray`, `fullbright`, `tracer`, `derp`(다른 플레이어에게 내 머리가 미친 듯이 돌아가는 것처럼 보이게), `freecam`(몸은 그대로 두고 카메라만 자유롭게 날아다니기), 인월드 `video` 재생, 커스텀 `skin` 변경.
- **채팅 도구**: 위장 채팅과 반복 채팅(`say`, `spam`, `faketext`).
- **외부 도구 연동**: 바닐라 `wsserver`와 호환되는 WebSocket 엔드포인트(설정 탭에서 주소 지정)를 자동으로 열어서 별도의 인게임 명령 없이도 외부 도구를 붙일 수 있고, `wssay` / `wsspam` / `whisperwspam` 중계도 별도 런타임 설치 없이 내장되어 있습니다.
- **커스텀 로컬 리소스팩**: 인게임 HUD 전용으로 자동 적용되며, 서버 자체의 리소스팩과는 무관하게 동작합니다.
- **Android 앱**: 같은 프록시를 APK 하나로 사이드로드할 수 있게 패키징했고, Windows와 동일한 Connect / Modules / Console / Settings 패널에 더해, 마인크래프트 위에 그대로 펼쳐지는 드래그 가능한 플로팅 오버레이 버블까지 있어서 화면 전환 없이 바로 조작할 수 있습니다. Termux도, 별도 Android용 Node.js 빌드도 필요 없습니다.

## 요구 사항

### Windows

- Windows 10/11, 64비트.
- Xbox Live에 로그인된 Microsoft/Xbox 계정, 그리고 이미 친구로 등록되어 있거나 본인이 소유한 대상 월드/Realm (Ender-Proxy는 Xbox Live를 통해 세션을 탐색하며, 임의의 서버 IP에 직접 접속하지 않습니다).
- FFmpeg은 릴리스 zip에 이미 포함되어 있습니다(`bin\ffmpeg.exe`). `/.video` 모듈을 쓰기 위해 따로 설치할 필요가 없습니다.
- 그 외에 따로 설치할 게 없습니다. `wssay` / `wsspam` / `whisperwspam`도 `enderproxy-gui.exe` 안에서 전부 처리되며, Node.js를 비롯한 어떤 별도 런타임도 필요 없습니다.

### Android

- Android 8.0(API 26) 이상, 64비트 ARM(`arm64-v8a`). 최근 몇 년 사이 나온 실제 안드로이드 폰이면 사실상 다 해당합니다. 32비트 전용 구형 기기 일부만 아직 지원 안 됩니다.
- Windows와 동일하게 Microsoft/Xbox Live 계정이 필요합니다.
- APK 하나 외에는 설치할 게 없습니다. FFmpeg(그래서 `/.video`)만 아직 Android에서 지원 안 되고, 나머지는 다 됩니다.

## 다운로드 및 설치

두 플랫폼 파일 모두 같은 [Releases](../../releases) 페이지에 있습니다.

### Windows

1. 최신 `Ender-Proxy-<version>-win64.zip`을 받습니다.
2. 원하는 위치에 압축을 풉니다 (쓰기 권한이 제한된 `C:\Program Files`는 피하세요).
3. `enderproxy-gui.exe`를 실행합니다.

압축을 푼 폴더 구조를 그대로 유지해야 합니다. `enderproxy-gui.exe`는 `resource_packs/`, `skins/`, `videos/`를 실행 파일 기준 **상대 경로**로 읽으므로, exe만 따로 빼서 다른 폴더로 옮기면 안 됩니다.

### Android

1. 최신 `Ender-Proxy-<version>-android-arm64.apk`를 받습니다.
2. 파일 앱이나 다운로드 알림에서 엽니다. 처음엔 "출처를 알 수 없는 앱 설치 허용" 팝업이 뜨는데 허용해주세요.
3. 앱을 엽니다. Windows와 달리 먼저 해야 할 별도 설정이 없습니다, 루프백 예외 명령어도 필요 없습니다. 그냥 열면 됩니다.
4. 로그인하고 나면 플로팅 오버레이("다른 앱 위에 표시") 권한을 물어봅니다. 선택 사항입니다. 마인크래프트 화면 위에 같은 컨트롤 패널을 그대로 펼칠 수 있게 해주는 기능일 뿐이라, 거절하고 앱 화면만 써도 되고 나중에 설정 탭에서 켤 수도 있습니다.

APK에 로컬 HUD 리소스팩과 기본 스킨이 이미 포함되어 있고, 앱을 처음 실행할 때 자동으로 풀립니다.

## 시작 전에: 윈도우 루프백 예외 설정

마인크래프트 베드락(그리고 프리뷰 버전)은 UWP 앱이라서, 윈도우는 기본적으로 UWP 앱이 `127.0.0.1`(localhost)에 접속하는 것을 차단합니다. Ender-Proxy는 로컬에서 실행되고 마인크래프트 클라이언트는 이 프록시를 거쳐서 접속하므로, 처음 실행하기 전에 PC당 한 번은 이 제한을 풀어줘야 합니다. (이 단계는 Windows 전용입니다. Android는 앱끼리 루프백을 이런 식으로 막지 않아서 대응되는 작업이 없습니다.)

1. **관리자 권한으로 PowerShell**을 엽니다 (시작 버튼 우클릭 후 "터미널(관리자)" 또는 "Windows PowerShell(관리자)" 선택).
2. 사용 중인 버전에 맞는 명령어를 실행합니다.

   ```powershell
   # 마인크래프트 정식판 (Microsoft Store)
   CheckNetIsolation LoopbackExempt -a -n="Microsoft.MinecraftUWP_8wekyb3d8bbwe"

   # 마인크래프트 프리뷰(Preview) 판
   CheckNetIsolation LoopbackExempt -a -n="Microsoft.MinecraftWindowsBeta_8wekyb3d8bbwe"
   ```

3. `Ok.`가 뜨면 성공입니다. 이후 마인크래프트를 완전히 종료했다가 다시 켜주세요.

관련해서 알아두면 좋은 명령어입니다.

```powershell
# 현재 예외 처리된 앱 목록 보기
CheckNetIsolation LoopbackExempt -s

# 나중에 예외를 다시 취소(제거)하고 싶을 때
CheckNetIsolation LoopbackExempt -d -n="Microsoft.MinecraftUWP_8wekyb3d8bbwe"
```

이 설정은 로컬에서 동작하는 베드락 프록시나 서버 도구라면 공통적으로 필요한, 한 번만 하면 되는 표준 윈도우 설정입니다. Ender-Proxy나 마인크래프트 자체를 건드리는 게 아니며, 나중에 예외를 제거해도 별다른 부작용은 없습니다.

## Windows: 단계별 가이드

이런 도구를 처음 써본다면 이 섹션부터 순서대로 따라 하면 됩니다. 완전히 새로 받은 zip 파일부터 실제로 접속에 성공하기까지 전 과정을 설명합니다.

### 1단계: 루프백 예외부터 설정하기

PC당 한 번만 하면 됩니다. 위의 [시작 전에](#시작-전에-윈도우-루프백-예외-설정) 항목을 그대로 따라 하세요. 이 단계를 건너뛰면 마인크래프트가 "연결 중..." 상태에서 멈췄다가 시간 초과로 끊기는 경우가 대부분입니다.

### 2단계: zip 압축 풀기

`Ender-Proxy-<version>-win64.zip` 파일을 우클릭해서 "압축 풀기"를 선택합니다. `문서\Ender-Proxy`나 바탕화면처럼 일반적인 폴더에 풀어주세요. `C:\Windows`나 `C:\Program Files` 같은 시스템 폴더에는 풀지 마세요.

### 3단계: 프로그램 실행하기

압축을 푼 폴더 안의 `enderproxy-gui.exe`를 더블클릭합니다. 콘솔 창 없이 어두운 톤의 프레임리스 패널이 뜹니다. 만약 윈도우 SmartScreen이 파란색 경고 화면을 띄운다면(서명되지 않은 소규모 프로그램에서 흔히 나오는 정상적인 경고입니다), "추가 정보"를 클릭한 뒤 "실행"을 눌러주세요.

### 4단계: Xbox Live로 로그인하기

패널에 Microsoft 로그인 링크와 짧은 코드, 그리고 **LOG IN** 버튼이 표시됩니다. 버튼을 누르고 브라우저에서 그 링크를 열어 코드를 입력한 뒤, 평소 마인크래프트에서 쓰는 것과 같은 Microsoft 계정으로 로그인하세요. 로그인이 끝나면 패널로 돌아오면 자동으로 로그인 상태를 감지합니다. 로그인 정보는 디스크에 캐시되므로 매번 다시 로그인할 필요는 없습니다(계정을 바꾸고 싶을 때는 앱의 **FORCE LOGIN**을 사용하세요).

### 5단계: 세션 선택하기

**Connect** 탭의 **Friends** 서브탭에 Xbox Live 친구들이 열어둔 활성 베드락 세션 목록이 뜹니다. 원하는 세션 옆의 **CONNECT**를 누르거나, 다른 대상을 원하면 **Gamertag**, **LAN**, **Featured**, **Direct** 서브탭으로 전환하세요. Friends 목록에 아무것도 뜨지 않는다면, 친구가 월드를 "친구"나 "친구의 친구"에게 공개했는지, 그리고 둘 다 Xbox Live에 로그인되어 있는지 확인해주세요.

### 6단계: 마인크래프트를 프록시에 연결하기

마인크래프트 베드락을 직접 실행해서 **플레이 → 서버**로 이동한 다음, `127.0.0.1`과 포트 `19132`(기본값, 접속 전 **Settings** 탭의 "Local RakNet Port"에서 변경 가능)를 가리키는 서버 항목을 추가하거나 기존 항목을 사용하세요. 그 서버 항목으로 접속하면, 마치 친구 월드에 직접 들어간 것처럼 접속되지만 이제는 프록시가 모든 패킷을 지켜보고 중계하는 상태가 됩니다.

### 7단계: 첫 명령어 사용해보기

마인크래프트 채팅창에 다음을 입력합니다.

```
/.help
```

명령어 카테고리 목록이 표시될 것입니다. 먼저 위험 부담이 없는 명령어부터 테스트해보세요. 예를 들어:

```
/.pos
```

는 현재 좌표를 보여주고,

```
/.menu
```

는 인게임 HUD 메뉴를 열어줍니다. 이후에는 아래 [명령어](#명령어) 표에서 전체 목록을 확인하며 하나씩 사용해보면 됩니다.

### 문제 해결

| 증상 | 해결 방법 |
|---|---|
| 마인크래프트가 "연결 중..."에서 멈추거나 바로 접속 실패한다 | [루프백 예외](#시작-전에-윈도우-루프백-예외-설정) 설정을 다시 하고, 마인크래프트를 완전히 종료했다가 재실행하세요. |
| 친구 세션이 하나도 뜨지 않는다 | 친구에게 일시정지 메뉴에서 월드를 "친구" 또는 "친구의 친구"에게 공개해달라고 요청하고, 둘 다 Xbox Live에 로그인되어 있는지 확인하세요. |
| 윈도우 SmartScreen이 실행을 막는다 | "추가 정보"를 누른 뒤 "실행"을 클릭하세요. 코드 서명이 되어 있지 않은, 개인이 배포하는 실행 파일에서는 흔히 나오는 경고입니다. |
| `/.video`가 아무 반응이 없다 | `enderproxy-gui.exe` 옆의 `bin\ffmpeg.exe`가 그대로 있는지(`bin` 폴더를 지우지 않았는지) 확인하고, `videos/` 폴더에 영상/GIF 파일을 넣었는지 또는 `http(s)://` 링크를 직접 입력했는지 확인하세요. |
| `wssay` / `wsspam` / `whisperwspam`을 써도 채팅에 아무것도 안 뜬다 | 접속 직후라면 몇 초 기다려주세요. 실제 클라이언트가 자체 핸드셰이크를 먼저 끝내야 합니다. 그래도 안 되면 월드에 다시 접속해서 연동이 다시 맺어지게 해주세요. |
| 로그인 링크/코드가 작동하지 않는다 | 본인의 마인크래프트/Xbox Live 계정과 같은 Microsoft 계정으로 로그인하고 있는지, 그리고 PC 시스템 시계가 정확히 맞춰져 있는지 확인하세요(시계가 틀리면 Microsoft 로그인 자체가 실패할 수 있습니다). |

## Android: 단계별 가이드

위의 Windows 가이드랑 거의 같은 흐름입니다, 폰 앱으로 하는 것뿐입니다. Android에는 루프백 예외 설정 단계가 없습니다, 그건 Windows 전용 요구사항입니다.

### 1단계: APK 설치

[Releases](../../releases)에서 `Ender-Proxy-<version>-android-arm64.apk`를 폰에 받아서 엽니다. 처음엔 "이 출처에서 설치 허용" 팝업이 뜨는데 허용하면(설정 → 허용) 정상적으로 설치됩니다.

### 2단계: 앱 열고 로그인하기

Ender-Proxy 아이콘을 탭합니다. Microsoft 로그인 링크와 짧은 코드, **LOG IN** 버튼이 있는 로그인 화면이 나옵니다. 폰 브라우저로 그 링크를 열어서 코드를 입력하고, 마인크래프트/Xbox Live 계정으로 로그인한 뒤 Ender-Proxy 앱으로 돌아오면 자동으로 로그인 상태를 감지합니다. 알림 권한 팝업이 뜨면 허용해주세요, "Ender-Proxy running" 알림을 계속 띄우기 위한 것뿐입니다.

### 3단계: 오버레이 허용하기 (선택 사항)

로그인 직후 플로팅 오버레이 허용 여부를 물어봅니다. 화면 어디든 작은 버블을 띄워두고 탭하면 마인크래프트 위에 그대로 전체 컨트롤 패널이 펼쳐지는 기능이라, 앱을 오가지 않아도 됩니다. 지금 허용해도 되고, 나중에 설정 탭에서 허용해도 되고, 아예 건너뛰고 앱 화면만 써도 됩니다.

### 4단계: 세션 선택하기

**Connect** 탭의 **Friends** 서브탭에 Xbox Live 친구들이 열어둔 활성 베드락 세션 목록이 뜹니다. 원하는 세션 옆의 **CONNECT**를 탭하거나, 다른 대상을 원하면 **Gamertag**, **LAN**, **Featured**, **Direct** 서브탭으로 전환하세요.

### 5단계: 마인크래프트를 프록시에 연결하기

마인크래프트 베드락(같은 폰)을 열어서 **플레이 → 서버**로 이동해서 `127.0.0.1`, 포트 `19132`(접속 전 **Settings** 탭에서 변경 가능)를 가리키는 서버를 추가합니다. 접속하세요, Windows 가이드와 동일합니다.

### 6단계: 첫 명령어 사용해보기

마인크래프트 채팅에 `/.help`를 입력하고, 이어서 `/.pos`나 `/.menu`도 써보세요. 전체 목록은 아래 [명령어](#명령어) 표를 참고하거나, 명령어를 직접 입력하는 대신 **Modules** 탭에서 탭 한 번으로 켜고 끌 수도 있습니다.

### 7단계: 끄는 방법

앱 화면만 닫거나, 마인크래프트로 전환하거나, 오버레이를 접어도 **꺼지지 않습니다**. 게임하는 동안 살아있어야 하니 일부러 그렇게 만들었습니다. 반면 최근 앱 목록에서 Ender-Proxy를 완전히 스와이프해서 지우면(단순히 백그라운드로 보내는 게 아니라 앱을 종료하면) 자동으로 꺼지고 오버레이도 사라집니다. 앱이나 오버레이 패널의 **STOP** 버튼, 또는 알림에 있는 **Stop** 버튼으로도 끌 수 있습니다. 아래 [Android 관련 참고사항](#android-관련-참고사항)도 참고하세요.

### 문제 해결

| 증상 | 해결 방법 |
|---|---|
| APK 설치가 안 된다 | 설치 허용 팝업이 떴을 때 허용했는지 확인하세요. 기기에 따라 설정 → 앱 → 특별 접근 → 알 수 없는 앱 설치, 여기서 브라우저나 파일 앱별로 따로 허용해야 할 수도 있습니다. |
| 친구 세션이 하나도 뜨지 않는다 | Windows와 동일: 친구에게 월드를 "친구" 또는 "친구의 친구"에게 공개해달라고 요청하고, 둘 다 Xbox Live에 로그인되어 있는지 확인하세요. |
| 마인크래프트가 `127.0.0.1:19132`에 접속이 안 된다 | Ender-Proxy 앱(또는 알림)이 아직 실행 중인지, 포트를 정확히 입력했는지 확인하세요. Windows와 달리 루프백 예외를 따로 확인할 필요는 없습니다. |
| 오버레이 버블이 안 뜨거나, 권한을 물어본 적이 없다 | 앱의 **Settings** 탭에서 "Floating overlay over game" 아래 **GRANT PERMISSION**을 누르세요. 일부 제조사(MIUI, ColorOS 등)는 시스템 설정에서 이 항목을 "다른 앱 위에 표시" 같은 다른 이름으로 숨겨둡니다. |
| 오버레이 원이 찌그러져 보이거나, 펼친 패널 아래쪽이 잘려 보인다 | 최신 릴리스로 업데이트하세요. Android 첫 빌드 이후 수정된 문제입니다(이제 오버레이가 화면 크기에 맞춰지고 Restart/Stop이 항상 보입니다). |
| `/.video`가 아무 반응이 없다 | 정상입니다, 아직 Android용 FFmpeg이 번들되어 있지 않습니다. |

## Android 관련 참고사항

- **끄는 방법**: 백그라운드(포그라운드 서비스)로 일부러 돌아갑니다, 마인크래프트로 전환해도 안 죽어야 하니까요. 앱을 백그라운드로 보내거나, 마인크래프트로 전환하거나, 오버레이를 접어도 꺼지지 않습니다. 최근 앱 목록에서 완전히 스와이프해서 종료하면(단순 백그라운드가 아니라) 자동으로 꺼지고 오버레이도 사라집니다. 앱/오버레이 패널의 **STOP** 버튼이나 알림의 **Stop** 액션으로도 끌 수 있습니다.
- **플로팅 오버레이**: 프록시 상태를 색깔 테두리로 한눈에 보여주는 작은 드래그 가능 원이며, 탭하면 그 자리에서 앱과 완전히 동일한 Connect/Modules/Console/Settings 패널로 펼쳐져서 마인크래프트를 벗어나지 않고 조작할 수 있습니다. 탭해도 앱 화면으로 전환되지 않으며, 앱으로 가고 싶으면 펼친 패널 헤더의 작은 "전체 앱 열기" 버튼을 쓰세요. "다른 앱 위에 표시" 권한이 필요하며, 첫 로그인 후 한 번 물어보고 이후에는 설정 탭에서 언제든 켜고 끌 수 있습니다.
- **권한**: 인터넷 접근, 알림("실행 중" 상태 표시용), 그리고 플로팅 오버레이용 "다른 앱 위에 표시" 권한(선택)이 필요합니다. 모두 별도의 위험 권한 설명 없이 시스템이 한 번 물어보는 수준입니다.
- **로컬 포트와 외부 도구 연동 주소**: 예전 콘솔 빌드와 달리 앱 자체의 **Settings** 탭에서 접속마다 설정할 수 있습니다(Windows 패널과 동일한 항목). `19132` / `127.0.0.1:8000`은 여전히 기본값일 뿐 고정값이 아닙니다.
- **현재 제한 사항**: `/.video`는 아직 지원 안 됩니다(Android용 FFmpeg이 번들되어 있지 않음), 64비트 ARM(`arm64-v8a`) 기기만 지원합니다.

## 설정

Windows 패널과 Android 앱(오버레이 포함) 모두 실행 플래그 대신 동일한 **Settings** 탭을 제공합니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| Local RakNet Port | `19132` | 이 기기에서 마인크래프트가 접속할 로컬 포트 |
| External WS Bridge | `127.0.0.1:8000` | `wssay`/`wsspam`/`whisperwspam`과 외부 도구용 주소. 비워두면 비활성화 |
| Floating overlay (Android 전용) | 권한 허용 전까지 off | 위에서 설명한 드래그 가능 오버레이 버블 켜고 끄기 |
| Log Out | — | 캐시된 Xbox Live 로그인 정보 삭제, 다음에 다시 로그인해야 함 |

## 선택적 구성 요소

### 영상 재생 (FFmpeg, Windows 전용)

`/.video`는 영상이나 GIF를 프레임 단위로 디코딩해서 인월드 파티클 화면에 그려줍니다. 릴리스 zip에 `bin\ffmpeg.exe`가 이미 포함되어 있어서 별도 설치 없이 바로 동작합니다. `videos/` 폴더에 원하는 영상/GIF 파일을 넣거나, `/.video`에 `http(s)://` URL을 직접 전달하기만 하면 됩니다.

릴리스 zip에는 영상 파일 자체는 포함되어 있지 않습니다. 권리가 없는 미디어를 재배포하지 않도록, 각자 준비해서 사용하세요.

Android 앱에는 아직 없습니다, Android용 FFmpeg이 번들되어 있지 않습니다.
